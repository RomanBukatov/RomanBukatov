### 🚀 Ключевые Проекты

#### 🌺 Мультивендорный Маркетплейс (Аналог Flowwow)
*Масштабируемая E-commerce платформа на передовом стеке.*
- **Ядро:** .NET 10 Backend + React Vite Frontend.
- **Архитектура:** Модульный монолит (Modular Monolith), спроектированный под высокие нагрузки.
- **Функционал:** Управление вендорами, сложный каталог, процессинг заказов в реальном времени.
- **Статус:** В активной разработке.

#### 📊 SaaS-панель: AI-Автоответы для Ozon & Wildberries
*Full-stack веб-решение для автоматизации работы с отзывами и аналитики.*
- **Стек:** .NET 8 Web API + React Vite (SPA).
- **Фичи:**
  - Защищенная система авторизации и ролей.
  - **Интерактивная аналитика:** Графики и метрики работы менеджеров.
  - **Настройка AI:** Интерфейс для тонкой настройки промптов под каждый маркетплейс.

#### 📈 Крипто-Снайпер и Мониторинг Фандинга
*Инструмент для высокочастотного мониторинга арбитражных возможностей.*
- **Ядро:** .NET 8, работа с WebSocket потоками.
- **Фичи:** Отслеживание Funding Rates на Binance, Bybit, OKX в реальном времени.
- **Производительность:** Оптимизирован под низкую задержку (Low Latency <100ms).

#### 🔐 Сервер Лицензирования ПО
*B2B система защиты десктопного софта.*
- **Ядро:** ASP.NET Core Web API.
- **Фичи:** Привязка к железу (HWID), удаленная активация/деактивация, логика Trial-периодов.
